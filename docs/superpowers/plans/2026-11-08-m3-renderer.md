# M3 Plan — Renderer (DreamerProvider, Board, useBoard, default components, themes, motion)

Date: 2026-11-08
Predecessor: M2 Core (`d5fb9ae`+docs, reviewer-approved). Branch: `master`.

## Goal

React layer that turns the headless M2 engine into an animated, interactive board:
`DreamerProvider` + `useBoard` + `<Board>`, default components for `text`, `choices`,
`callout`, `steps`, `group`, inline marks (`highlight`, `emphasis`, `term`, `focusable`),
theme system (`light` + `dark`), Motion-based driver with reduced-motion fallbacks.

## M3 acceptance (from AGENTS.md §10)

- Playground renders `fixtures/define-biology.json`.
- Clicking a `choices` item fires `select` (intent `navigate`) / `answer` (intent `answer`).
- Keyboard operable.
- axe checks pass (component tests via `jest-axe` — Storybook stories land in M7).
- Reduced motion renders everything instantly (`prefers-reduced-motion`).

## Tasks

1. **React runtime surface** (`src/react/`, zero React imports upstream in `schema/`+`core/` stays true):
   - `provider.tsx`: `DreamerProvider` — context carrying `registry`, `theme`, `onEvent`, `onError`, i18n strings.
   - `use-board.ts`: `useBoard()` wrapping `BoardResolver` with `useSyncExternalStore`; exposes `state`, `applyFinal`, `applyPartial`, `applyOps`, `back`, `reset`, `events`, `errors`.
   - `board.tsx`: `<Board>` renders nodes in insertion order, polite live region for appends, per-node `enter.order` sequencing.
2. **Theme system** (`src/theme/`): CSS-variable token set (colour roles, fonts, radius, spacing, motion durations/easings), `light` + `dark` presets, `<ThemeProvider token overrides>` applied as CSS custom properties on a wrapper; no CSS framework required.
3. **Motion driver** (`src/react/motion/`): `MotionDriver` interface (enter/emphasis/exit presets named exactly as the schema enums); implementation on `motion/react` with `LazyMotion`+`m`; `useReducedMotion` fallback → instant/fade. GSAP NOT touched (deferred to M5 per DECISIONS).
4. **Default components** (`src/react/components/`): `TextBlock` (renders `Inline[]` with mark renderers: highlight/emphasis/term/focusable), `Choices` (chips/list/grid; React Aria buttons; emits `select`/`answer`; keyboard + focus ring), `Callout`, `Steps` (sequential reveal via enter orders), `Group` (stack/row/grid of nested blocks via same renderer — recursion over `BlockSchema` union).
5. **Package wiring**: `exports["."]` → react surface; keep `./core`, `./schema` intact; React/`motion`/`@react-aria/*` as peer/regular deps; React 19.
6. **Playground scaffold** (`apps/playground/`): minimal Next.js app — fixture picker (starts with `define-biology.json`), JSON source view, live `<Board>`, event log panel + error log panel. No mock tutor yet (that's M7's canned-reply loop; here we only need fixture → board).
7. **Tests** (`tests/react/`): Testing Library + `jest-axe` (jsdom/happy-dom env in vitest):
   - define-biology fixture renders; highlight mark visible; choices item click emits `select` with ref/label; answer intent emits `answer` value; keyboard Tab+Enter on a choice works.
   - reduced-motion: all content present with no animation timers pending.
   - theme tokens: light/dark swap sets expected CSS variables.
   - unknown/invalid node renders fallback + onError fires (M2 registry path, now end-to-end).
8. **Verification**: `pnpm test` (all suites), `pnpm lint`, build emits react chunk; confirm `schema/`+`core/` still React-free by grep.

## New dependencies (gate: §9 — flag before install)

- Runtime: `react@^19`, `react-dom@^19`, `motion`, `@react-aria/focus`, `@react-aria/interactions` (+`@react-stately/*` as needed by React Aria).
- Dev: `@testing-library/react`, `@testing-library/user-event`, `jest-axe`, `@types/jest-axe`, `jsdom`, `next@^15` (playground), `typescript` types.
- No paid services, no network calls in the library — playground fetches only local fixtures.
