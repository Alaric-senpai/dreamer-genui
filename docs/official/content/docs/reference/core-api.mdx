`dreamer-genui/core` has no React and no DOM dependency. Everything here runs in a server, a worker, a test or a CLI.

```ts
import { createRegistry, definePlugin, createBoardResolver, readingSchedule } from 'dreamer-genui/core';
```

## Registry

```ts
const registry = createRegistry();
registry.use(plugin, { override?: boolean });
registry.register(kind, name, value);
registry.override(kind, name, value);
registry.get(kind, name);
registry.list(kind?);
registry.listValues(kind);
registry.enable(name); registry.disable(name);
registry.disableEntry(kind, name);
registry.listModelConnectors();
registry.listMiddleware();
```

Priority: host override → later plugin with `override: true` → earlier plugin → built-in. Built-ins start at `0`; third-party entries increment from `10`.

## Resolver

```ts
createBoardResolver(options?: ResolverOptions): BoardResolver
```

```ts
interface ResolverOptions {
  registry?: Registry;
  onError?: (error: LibraryError) => void;
  theme?: Partial<ThemeContext>;
  middleware?: MiddlewareDefinition[];
  locale?: string;
  dir?: 'ltr' | 'rtl';
  clock?: Clock;
  examLocks?: Partial<ExamLockPolicy>;
  examLockStrategy?: 'queue' | 'reject';
}
```

`BoardResolver` owns the state, the cue plan, assessments, buses and the ops log. `createBoardStore()` from `dreamer-genui/react` is a thin React-friendly wrapper around it.

## Theme

```ts
createThemeResolver(context: ThemeContext): (spec: ThemeSpec) => ThemeResolution
```

```ts
type ThemePolicy = 'none' | 'moods' | 'moods+tokens';

interface ThemeContext {
  policy: ThemePolicy;
  allowedMoods?: string[];
  allowedAmbience?: string[];
  allowedFonts?: string[];
  baseline?: ThemeSpec;
  onThemeAdjusted?: (roles: string[]) => void;
}

interface ResolvedTheme {
  spec: ThemeSpec;
  mood?: string;
  intensity: number;
  ambience?: { preset: string; intensity: number };
  surface?: string;
  tokens: ThemeTokens;
  transition: { duration: number; ease: EaseName };
}
```

`ThemeResolution` reports the resolved theme plus whether it was rejected or adjusted.
